# A knob's value on hover, on a wide window

Hovering a knob or fader shows its value in place of its name only where the value is not already on screen (phones and narrow windows). On a wide window, where every knob's value is printed under it, hovering changes nothing.

## Why this is out of scope

The owner, 2026-10-28: "On large screen, we already see the values below the knobs. No need to duplicate the information!" Showing the value twice, once under the knob and once in its name's place, adds movement for no new information.
