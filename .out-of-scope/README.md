# Out of scope

Feature ideas the owner has turned down, one file per idea, each with the reason, so the same idea coming back (from the inbox, a review or a visitor) meets the earlier answer instead of starting over ([ADR-0012](../docs/adr/0012-following-the-ai-hero-skills.md), point 5). A later "yes" deletes the file.

Only rejected features come here. A bug that is not one, a slip already made, or an idea already built goes to the inbox's Dropped list with its reason.

Each file: a title naming the idea, what Limpide does instead, **why** (the owner's words where there are some), and the requests that asked for it.
