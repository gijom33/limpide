# MIDI Learn first; no hard-coded Controller map

We target the Synido TempoPAD C16, which has 8 endless encoders, 4 faders, 16 velocity pads and 12 buttons. But its default CC and note assignments aren't published, every control is user-assignable on the device, and its encoders may report Absolute or Relative values depending on firmware. So Limpide ships no hard-coded CC table. Every Mapping is created by MIDI Learn, guided for the C16 by a Quick Setup. During Learn the Encoder Mode is detected from the values received: values clustered at 1/127 or 63/65 are Relative, anything else is Absolute with Pickup. Mappings are saved locally.
