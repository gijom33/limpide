# Code of conduct

Limpide follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/): be kind, assume good faith, and keep criticism about the work, not the person. Harassment, insults and personal attacks are not welcome in the Issues, the pull requests or anywhere the project is discussed.

To report a problem privately, write to the maintainer, [Guillaume Boillet](https://www.linkedin.com/in/guillaume-boillet-18208310). Reports are read in confidence. The maintainer may remove comments, close discussions or block people who break this code.
